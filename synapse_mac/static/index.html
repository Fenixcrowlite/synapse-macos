02 · Backup / ngrok

Checking...

Install ngrok and configure its token in Terminal first: ngrok config add-authtoken YOUR_TOKEN. launchd keeps the reserve tunnel alive after login.

Important: the Web UI works on either HTTPS URL without a ChatGPT subscription. ChatGPT Free/Go may not invoke custom MCP plugin tools inside ChatGPT; use a browser or independent MCP client instead. Neither tunnel is a separate macOS process server: both depend on this local agent being alive.
